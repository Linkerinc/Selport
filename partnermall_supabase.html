이 툴의 동작 방식

  1. 3M 파트너몰에서 다운로드한 엑셀 파일을 업로드하세요 (.xlsx 형식)
  2. 주문번호를 고유 키로 사용해 자동으로 중복을 제거하고, 같은 주문이 다시 올라오면 최신 파일 내용으로 덮어씁니다
  3. 데이터는 이 브라우저의 IndexedDB에 저장됩니다 (다른 PC에서는 접근 불가)
  4. 월별로 자동 그룹핑되며, 필요시 개별 월 청크를 삭제할 수 있습니다
  5. 전체 누적 데이터는 언제든 CSV/엑셀로 내보낼 수 있습니다
기술: IndexedDB · SheetJS · Pretendard · 단일 HTML · 외부 서버 미사용 (모든 데이터 로컬 보관)

👤 방문자 유형 로그인 회원 vs 비회원(게스트) · 선택 기간

일자별 추이 · 회원/비회원 방문
대리점별 회원 비중 · 로그인 회원 비율 높은 순
로그인 회원 비중이 높을수록 단골·충성 고객이 많다는 신호예요. 비회원(게스트)은 로그인 없이 둘러본 방문이에요.

📖 페이지 완독률 페이지를 끝까지(90% 스크롤) 본 비율 · 조회 많은 페이지 순

완독률 = 그 페이지를 본 사람 중 90%까지 스크롤해 사실상 끝까지 본 비율이에요. 조회는 많은데 완독률이 낮으면 윗부분만 보고 이탈하는 페이지예요(예: 회원가입 폼 완독률이 낮으면 가입 중 이탈). 장바구니·로그인 같은 처리용 페이지는 제외했고, 조회 30회 미만 페이지도 비율이 튀어 뺐어요.

🧭 회원가입 퍼널 안내 → 약관 → 정보입력 → 입력시작/제출 → 완료

각 단계로 넘어간 사용자 수예요. 단계 사이 이탈률이 높은 곳이 병목이에요. 입력 시작/제출 단계로 "페이지엔 왔는데 입력도 안 한 사람"과 "입력하다 포기한 사람"이 구분돼요. 개인/기업 토글은 7/2 이후 데이터부터 정확해요(그 전엔 약관 단계만 구분값이 있었어요). B2B 특성상 표본이 얇으니 기간을 넓혀 보세요.

🖱 클릭 분석 상단 탭 · 메인 배너 · 이벤트 참여 클릭 (7/6 수집 시작)

📑 상단 탭 클릭 TOP · 어느 메뉴를 많이 누르나
🖼 메인 배너/영역 클릭 TOP · 어느 배너가 먹히나
🎰 이벤트/기획전 참여 · 룰렛 돌리기 등 실제 참여 횟수
메인 화면에서 사용자가 실제로 무엇을 누르는지예요. 탭 클릭이 많은 메뉴가 관심사이고, 배너 클릭이 적으면 배너 교체 신호예요. 참여 수는 실제 참여 성공 기준(자격 없는 클릭 제외)이에요.

👥 회원별 관심 상품 누가 무엇을 보고 있나 · 영업 골든리스트 (7/8 수집 시작)

로그인 회원이 실제로 조회한 상품을 회원 단위로 모아 보여줘요. 조회가 많은데 최근 구매가 없는 회원이 영업 우선순위예요. 행을 누르면 그 회원이 본 상품 전체가 보이고, 조회만 하고 주문 이력이 없는 상품은 붉은색(미구매)으로 표시돼요. 회원 식별은 해시 매칭 기반이라 주문 이력이 있는 회원만 업체명이 표시돼요(그 외에는 익명 처리).
GA4 데이터를 불러오지 못했어요. (권한 또는 연결 확인 필요)
